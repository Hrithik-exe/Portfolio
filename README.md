# Portfolio Website

A minimalist black and white portfolio website with an easy-to-use admin panel.

## 🌐 Live Site

https://hrithik-exe.github.io/Portfolio

## 📝 How to Update Your Portfolio

### Step 1: Open Admin Panel
- Open `admin.html` in your browser (double-click the file)
- Your current content will load automatically

### Step 2: Edit Your Content

**Hero Section:**
- Name
- Title
- Description

**About Section:**
- 3 paragraphs about yourself

**Experience:**
- Click "+ Add Experience" to add new jobs
- Fill in: Date, Title, Company, Description
- Click "Remove" to delete an experience

**Skills:**
- Enter skills separated by commas
- Categories: Languages, Web, Databases, AI Platforms, Other

**Projects:**
- Click "+ Add Project" to add new projects
- Fill in: Title, Description, Technologies (comma separated), Link
- Click "Remove" to delete a project

**Contact:**
- Email
- Location

**Social Links:**
- GitHub URL
- LinkedIn URL
- WhatsApp URL

### Step 3: Save Your Changes
- Click "Save Changes" button (saves in your browser)

### Step 4: Export HTML
- Click "Export HTML" button
- A new `index.html` file will download

### Step 5: Replace Old File
- Replace your old `index.html` with the downloaded file

### Step 6: Push to GitHub
```bash
git add .
git commit -m "Updated portfolio content"
git push
```

### Step 7: Wait & Refresh
- Wait 2-5 minutes for GitHub Pages to deploy
- Hard refresh your site: Ctrl+Shift+R (or Cmd+Shift+R on Mac)

## 🖼️ Update Profile Picture

1. Replace `profile.jpeg` with your new photo (keep the same filename)
2. Or rename your photo to `profile.jpeg`
3. Push to GitHub:
```bash
git add .
git commit -m "Updated profile picture"
git push
```

## 💡 Quick Tips

- Always click "Save Changes" before exporting
- Always use `git add .` to commit all files
- Check GitHub Actions tab to see deployment progress
- Clear browser cache if changes don't appear
